Authentication

Every API request needs a valid customer key. Keys can be disabled, expired and quota-limited from the admin panel.

A request is counted after the upstream response is received. Reaching the configured quota returns HTTP 429.

Response

The successful upstream JSON body is returned without wrapping, renaming or filtering its fields.
